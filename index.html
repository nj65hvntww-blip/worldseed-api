WORLDSEED • v0.1 demo

Worlds begin with a seed.

A developer-friendly concept for persistent, shared fictional universes. This first release is a browser-only prototype. No hosted write API or shared storage exists yet.

Generate a demo world

Press Generate world to see a JSON result.

Planned API

These routes are a design proposal, not live endpoints:

POST /v1/worlds
GET /v1/worlds/{worldId}
POST /v1/worlds/{worldId}/events
GET /v1/worlds/{worldId}/history

Next: add a secure backend, API keys, and permanent event history so iPhone Shortcuts can send real requests.
